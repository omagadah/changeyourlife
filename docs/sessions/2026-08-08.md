# Session 2026-08-08 - Refonte : l'ORGANIZER devient le cerveau du site

SW **v168 → v169**. Changement de cap produit décidé par l'owner : construire le
site **pour lui-même**, pas pour un utilisateur imaginaire.

## Le cap

> « Lorsqu'on se connecte, ce qui m'importe, c'est l'organiseur. Toutes les idées
> en vrac vont dans cet espace. Il faut que ce soit relié au Google Agenda. Le but
> c'est de mettre une IA dedans, et qu'elle régisse absolument tous les modules. »

Traduction en règles de conception :

1. **L'ORGANIZER est le cerveau.** Il arrive tout en haut de `/app/`, avant tout
   le reste. Le message d'accueil devient une ligne discrète.
2. **Google Agenda est le bras.** Une fiche planifiée devient un vrai événement.
3. **SYL est au-dessus de tout.** Une seule IA, qui lit l'état réel du système.
4. **L'arbre reste, mais recule.** Il devient le *reflet* de l'action (260 px,
   sous les blocs utiles), pas le sujet. La direction artistique est conservée.
5. **Maslow relie les deux** : chaque fiche est rattachée à une branche, et son
   XP part sur CETTE branche quand elle est terminée.

## Travaux effectués

### 1 · `/js/gcal.js` - connecteur Google Agenda unifié (+ bug bloquant corrigé)

**Bug trouvé à la reprise** : `agenda.js` écrivait le jeton OAuth en
`sessionStorage` avec le scope **`calendar.events.readonly`**, tandis que
`organizer.js` le relisait en **`localStorage`** pour tenter une **écriture**.
Double cause → le bouton « Ajouter à l'Agenda » de l'ORGANIZER ne pouvait
**jamais** fonctionner, quel que soit l'état de la connexion.

Correctif : un module unique `/js/gcal.js`.
- Scope **`calendar.events`** (lecture **et** écriture), jeton en `sessionStorage`,
  purge automatique de l'ancien emplacement `localStorage`.
- API : `connect/disconnect/isConnected/canWrite`, `listToday/listRange/listUpcoming`,
  `createEvent/deleteEvent`, formatage (`fmtEventTime`, `isAllDay`), export `.ics`.
- Codes d'erreur explicites (`gcal/expired`, `gcal/forbidden`, `gcal/not-connected`)
  → un 403 (scope insuffisant) affiche « reconnecte pour autoriser l'écriture »
  au lieu d'un échec muet.
- `agenda.js`, `agenda-page.js` et `organizer.js` passent tous par ce module.
  **Important** : `/agenda/` ne peut plus reconnecter en lecture seule et
  rétrograder le jeton (ce qui aurait recassé la planification).

⚠️ **Conséquence pour l'owner** : le scope OAuth a changé → il faut **reconnecter
Google Agenda une fois** (écran de consentement Google, cette fois avec l'écriture).

### 2 · `/js/organizer-data.js` - schéma partagé (v2)

Un seul modèle de données pour la page `/organizer/` et le hub de `/app/`.
- Fiche enrichie : `branch` (clé Maslow) + `gcalId` (événement lié).
- `topPriorities()` / `dueToday()` : classement par colonne Eisenhower pondéré par
  l'échéance (retard = +60, aujourd'hui = +45…).
- `guessBranch()` : heuristique locale qui pré-range une capture (« appeler maman »
  → appartenance, « payer le loyer » → sécurité, « lire » → cognitif). Suggestion
  seulement - l'utilisateur corrige en un clic.
- `saveBoard()` remonte l'échec d'écriture (toast) au lieu de le perdre en silence
  (finding AUDIT P0 #2).

### 3 · `/js/app-organizer.js` - le hub en tête de `/app/`

- **Capture en une ligne** toujours visible : « Déverse une idée… » + Entrée.
- 4 colonnes Eisenhower compactes (`À trier`, `Urgent · Important`, `À planifier`,
  `Vite fait / déléguer`), **drag & drop** (SortableJS), compteurs.
- Clic sur une fiche → panneau : **branche Maslow** (8 boutons), échéance
  (Aujourd'hui / Demain / +7 j / date), priorité, **« Planifier dans Google
  Agenda »**, « Terminée (+50 XP) », suppression.
- Bouton **« SYL, aide-moi à trier »** : ouvre le chat avec le contexte
  pré-rempli. Jamais d'envoi automatique - l'utilisateur relit et valide.

### 4 · SYL centrale - `/api/syl-brief.js` + `/js/syl-brief.js`

SYL ne répond plus seulement quand on lui parle : elle **regarde**.
- Reçoit les fiches ouvertes (titre, priorité, branche, jours avant échéance, déjà
  dans l'agenda ?) et les événements des 3 prochains jours.
- Renvoie : `brief` (2-3 phrases), `profile` (**profil type** : comment tu
  fonctionnes, formulé comme une hypothèse), `focus` (≤ 3 fiches, dans l'ordre
  proposé), `nourries` / `jachere` (branches).
- **Posture non-directive renforcée dans le prompt** : pas de « commence par X »,
  pas de culpabilisation (« 12 tâches en retard » → « 12 fiches ont une échéance
  passée ; certaines n'ont peut-être plus lieu d'être »).
- Rate-limit **8/h/uid** (Firestore `briefRate`, fail-closed, deny dans les rules),
  cache client ~12 h, et **repli 100 % local** : sans IA, le bandeau dit quand même
  quelque chose d'utile (calculé côté client).
- L'état est envoyé **résumé en texte court**, pas en JSON brut recopié : moins de
  tokens, moins de surface d'injection.

Nouvel ordre d'arrivée :

| # | Bloc | Note |
|---|---|---|
| 1 | Ligne d'accueil | **minuscule** - 0.84 rem, une seule ligne |
| 2 | **ORGANIZER** | le cerveau |
| 3 | **SYL** | brief + profil type |
| 4 | **Ta journée** | agenda **et** fiches échues, fusionnés dans une timeline |
| 5 | Raccourcis | board complet · Aujourd'hui · Compétences (rangée compacte) |
| 6 | **L'arbre** | 260 px, sous les blocs utiles |
| 7 | Le reste | giveaway, chiffres, modules |

- Les 3 gros CTA empilés (plan / compétences / organizer) → une rangée de 3
  raccourcis discrets.
- Le CTA « Coach IA / Gemini 2.0 » **retiré** (doublon avec SYL - cf. AUDIT
  « 3 stacks IA concurrentes »).
- `agenda.js` réécrit : la carte agrège désormais les événements Google **et** les
  fiches ORGANIZER échues, triées ensemble, sans doublon (via `gcalId`).

### 6 · Maslow relié à l'organizer

- Sélecteur de branche dans la fiche, sur `/app/` **et** `/organizer/`.
- Liseré coloré + emoji de la branche sur chaque fiche.
- **L'XP d'une fiche terminée va sur sa branche** (avant : toujours
  « accomplissement »). L'arbre pousse donc là où l'action a réellement eu lieu.
