# Session 2026-08-26 - Audit, et une régression critique retrouvée

SW **v200 → v201**. Audit complet du codebase (le précédent datait du 16/08,
27 commits plus tôt), correctifs appliqués dans la foulée, puis remise à niveau
de la documentation.

## 1 · La trouvaille : le service worker n'était plus enregistré

Le commit `4af1833` du 20/08 (refonte du fond animé) a réécrit `common.js` et
**perdu le bloc `serviceWorker.register()`** - le seul du site.

```
grep -r "serviceWorker.register" public/   →   0 résultat
```

Conséquences pendant six jours :

- **tout nouveau visiteur** : ni installation PWA, ni offline, jamais ;
- les bumps de version du SW (v198 → v200) ne servaient qu'aux navigateurs
  ayant encore un ancien SW enregistré, qui re-vérifient le fichier d'eux-mêmes ;
- un utilisateur qui vidait son navigateur perdait le SW **définitivement**.

**Fix** (`d89f0ba`) : bloc réintroduit dans `common.js` (importé par toutes les
pages connectées via ESM), avec toast « Mettre à jour » via le `toast()` partagé ;
la vitrine, qui n'importe pas `common.js`, a le sien dans `home-boot.js`.
L'enregistrement attend l'événement `load` pour ne pas concurrencer le
chargement initial.

> **Leçon retenue, ajoutée à CLAUDE.md** : l'enregistrement du SW vit dans
> `common.js`. Il a déjà été perdu une fois lors d'une refonte de ce fichier.

## 2 · Plus un seul script depuis un CDN (`71e172c`)

Chart.js, SortableJS, three r134, vanta.birds et twemoji sont **vendorisés**
dans `public/vendor/`. Un seul commit ferme **quatre findings** de l'audit du 16/08 :

| Finding précédent | Pourquoi il tombe |
|---|---|
| Aucun SRI sur ~30 scripts CDN | Il n'y a plus de script CDN du tout |
| three r134 + vanta en CDN | Servis en local |
| Précache offline illusoire | Le SW ignorait le cross-origin ; tout est same-origin |
| Risque supply-chain cdnjs/jsdelivr | Plus de dépendance d'exécution à un tiers |

**Chart.js existait en trois versions** selon la page (4.4.0 sur `/app/`, 4.4.1
sur `/autoevaluation/`, 4.4.3 sur `/settings/`) : unifié en 4.4.3.

**CSP resserrée** : `script-src` passe de 4 origines à `'self'` + gstatic +
apis.google (Firebase/OAuth, incompressibles). `cdn.jsdelivr.net` et
`cdnjs.cloudflare.com` retirés de `script-src`, `style-src` **et** `connect-src`.

Les assets **images** des emojis (Fluent 3D, Twemoji SVG) restent en CDN : des
milliers de fichiers, couverts par `img-src https:`.
